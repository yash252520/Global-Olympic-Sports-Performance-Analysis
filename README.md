# Global Olympic Sports Performance Analysis

A data visualization project exploring Olympic history using Tableau and Flask.

### Features
- Olympic medal distribution analysis
- Top 10 countries by participation
- Top 10 sports by participation
- Tableau dashboard and story
- Flask-based web integration

### Tools Used
- Tableau
- Python (Flask)
- HTML

### Dataset
[120 Years of Olympic History — Kaggle](https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)

### Run Locally
```bash
pip install flask
python app.py
```

Open `http://127.0.0.1:5000/` in your browser.
